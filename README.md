# 🐾 Pet Care AI (Animal_Ai)

Hệ thống hỗ trợ quản lý và chăm sóc thú cưng tích hợp AI.

## 🚀 Công nghệ sử dụng

* **Frontend:** React, Vite, TypeScript, Tailwind CSS
* **Backend:** Node.js, Express
* **Database:** PostgreSQL (`petcare_postgres`)
* **DevOps:** Docker, Docker Compose
